# StackNestViewerKit

外部ビューアが StackNest の本を読み、読書位置を StackNest へ書き戻すための Swift パッケージ（0.1.0 の準備中）。

A Swift package for external viewers to read StackNest books and write the reading position back to StackNest
(0.1.0 is in preparation).

- 形式の文書と統合の手引きは 0.1.0 で置く。 / The format document and the integration guide come with 0.1.0.
